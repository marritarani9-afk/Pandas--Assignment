# Pandas Assignment

A structured Python-based assignment focused on **data manipulation, analysis, cleaning, and transformation using Pandas and NumPy**. This repository demonstrates practical understanding of core Pandas concepts through output prediction, code correction, edge-case handling, and scenario-based data analysis.

## 📌 Overview

This assignment covers fundamental and intermediate concepts in data analysis using Python. It includes practical exercises designed to strengthen understanding of DataFrames, Series, filtering, aggregation, statistical analysis, data cleaning, and data validation.

## 📚 Topics Covered

- Pandas Series and DataFrames
- NumPy Arrays and Broadcasting
- Boolean Filtering
- Descriptive Statistics
- GroupBy and Aggregation
- Sorting and Filtering
- Correlation Analysis
- Missing Value Handling
- Duplicate Detection and Removal
- Data Type Conversion
- Data Cleaning and Standardization
- Data Validation
- Handling Outliers and Invalid Values

## 🗂️ Assignment Structure

### Section A — Output Prediction
Predicting and analyzing the output of Pandas and NumPy operations.

### Section B — Code Correction
Identifying errors in Pandas code and applying appropriate corrections.

### Section C — Edge Cases
Understanding broadcasting, missing values, mixed data formats, and outlier handling.

### Section D — Scenario-Based Data Cleaning
Working with a real-world-style student assessment dataset involving:
- Department standardization
- Duplicate record detection
- Missing value handling
- Data type conversion
- Invalid mark identification
- Data validation
